## 2. VMware 네트워크 구축

### VM 저장 환경

VMware 가상머신은 별도의 저장 공간을 사용하기 위해 다음 경로에 구성하였다.

- VM Storage: `D:\VMware\SunTech`

### Client Network

- VMware Network: VMnet10
- Network: `10.10.10.0/24`
- Host Virtual Adapter: Disabled
- VMware DHCP: Disabled
- 용도: 사용자 PC 및 테스트 클라이언트

### Server Network

- VMware Network: VMnet11
- Network: `10.10.20.0/24`
- Host Virtual Adapter: Disabled
- VMware DHCP: Disabled
- 용도: 서버 인프라

VMware의 DHCP 기능은 사용하지 않고, 향후 실제 DHCP 서버인 DHCP01을 통해 클라이언트 IP를 할당하도록 구성하였다.

## 4. 네트워크 설정 검증

IP 설정 확인을 위해 다음 명령을 사용하였다.

    ipconfig /all

DNS 설정은 다음 명령을 통해 정적 설정 여부를 추가 확인하였다.

    netsh interface ipv4 show dnsservers

확인 결과 `10.10.20.10`이 정적 DNS 서버로 설정되어 있음을 확인하였다.

자기 자신에 대한 Ping 테스트도 수행하였다.

    ping 10.10.20.10

### 테스트 결과

- 전송: 4
- 수신: 4
- 손실: 0%
- Packet Loss: 0%

DC01의 기본 TCP/IP 설정이 정상적으로 적용되었음을 확인하였다.

## 5. 발생 문제 및 해결

### 문제: Windows Server 설치 화면 미표시

#### 증상

DC01 VM 최초 부팅 시 Windows Server 설치 화면이 표시되지 않고 다음과 같은 메시지가 나타났다.

    EFI Network...
    Time out

#### 원인

VM이 Windows Server 설치 ISO를 정상적인 부팅 미디어로 사용하지 못하고 네트워크 부팅을 시도하였다.

#### 해결

VMware의 `Power On to Firmware`를 사용하여 UEFI Firmware에 진입하였다.

부팅 장치와 Windows Server 2019 설치 ISO 연결 상태를 확인한 후 다시 부팅하여 Windows Server 설치 화면이 정상적으로 표시되는 것을 확인하였다.

#### 결과

Windows Server 2019 Standard Evaluation (Desktop Experience) 설치를 완료하였다.
