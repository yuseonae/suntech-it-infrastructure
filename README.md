# SunTech Manufacturing IT Infrastructure

제조기업의 본사 및 생산환경을 가정하여 기업 IT 인프라를 설계하고 구축하는 프로젝트입니다.

## 📌 Project Overview

본 프로젝트는 제조기업의 IT 인프라 운영 환경을 가정하여
네트워크, 서버, Active Directory, 파일 서버, 보안, 백업 및
시스템 운영 환경을 단계적으로 설계하고 구현하는 것을 목표로 합니다.

## 🏭 Company Environment

- 제조기업
- 본사 + 생산공장
- 임직원 규모: 추후 확정
- 부서별 업무 환경 및 권한 관리
- Windows 기반 사내 IT 환경

## 🎯 Project Goals

- 제조기업의 IT 인프라 요구사항 분석
- 기업 네트워크 및 IP/VLAN 설계
- Windows Server 기반 서버 인프라 구축
- Active Directory 기반 계정 및 조직 관리
- 부서별 파일 및 접근 권한 관리
- 보안 정책 및 감사 환경 구축
- 백업 및 복구 환경 구축
- 실제 IT 운영 상황을 가정한 장애 대응
